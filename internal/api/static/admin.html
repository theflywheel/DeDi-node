Operator console

Onboarding participants onto a Beckn network served by this node: who exists, what keys they present, and when they stop being valid. Onboarding is a governed act — every action here is an append to the transparency log, never an edit or a delete.

Preview mode. This node exposes no write API — publishing is operator tooling only (governance). Forms below generate the exact record and the dedid seed command to apply it, so the console is usable today and drops onto a publish endpoint unchanged.

Rotate a key

Rotation is a new version, not a replacement: the old key stays resolvable via ?as_on= so signatures on older messages still verify. Publish the new key before the old one expires so the windows overlap.

Revoke a participant

A revocation is a new version with state: revoked, never a deletion — history stays provable. Beckn wildcard lookups return live records only, so a revoked participant then 404s and ONIX rejects its messages with 401.
