Rotate a key

Rotation is a new version, not a replacement: the old key stays resolvable via ?as_on= so signatures on older messages still verify. Publish the new key before the old one expires so the windows overlap.

Revoke a participant

A revocation is a new version with state: revoked, never a deletion — history stays provable. Beckn wildcard lookups return live records only, so a revoked participant then 404s and ONIX rejects its messages with 401.

Child nodes

A child node is a separate node — its own identity key, its own database, its own log — holding a namespace this one delegates to it. That is a different thing from a replica and from a witness, and worth keeping straight:

ReplicaWitnessChild
Identitythis node's keya stranger's keyits own key
Logthis log, copiedits own, unrelatedits own, delegated
Buys youuptimetamper evidencea namespace someone else runs
This node never holds the child's private key. It issues a one-time enrolment offer; the child generates its own key on first boot and enrols by presenting the public half. A parent that had held the private key could forge the child's checkpoints forever, and the child's log would then prove nothing you had not already asserted yourself.
delegate a namespace

The namespace must sit exactly one level under this node's — you can only delegate what you hold.
