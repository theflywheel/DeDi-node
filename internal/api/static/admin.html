Rotate a key

Rotation is a new version, not a replacement: the old key stays resolvable via ?as_on= so signatures on older messages still verify. Publish the new key before the old one expires so the windows overlap.

Revoke a participant

A revocation is a new version with state: revoked, never a deletion — history stays provable. Beckn wildcard lookups return live records only, so a revoked participant then 404s and ONIX rejects its messages with 401.
