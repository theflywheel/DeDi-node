What this cannot tell you

That the log is append-only. An inclusion proof says this record is in the tree the checkpoint describes; it says nothing about whether that tree is an extension of the one the node published yesterday. Only a party who kept yesterday's checkpoint can establish that, which is what the ring is for, and what the evidence page shows in full.
